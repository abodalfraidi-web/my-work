# مساري — مساعدي الشخصي

تطبيق شخصي على الجوال (PWA) فيه: الأهداف وخططها، مهام اليوم، اليوميات، المصاريف والديون، الأشخاص وتحليلهم، المذاكرة والحفظ بالمراجعة المتباعدة، والتحليل. ومعه مساعد ذكي (Claude) يفهم الكلام الحر ويسجله.

- الكود في `app/` (React + TypeScript + Vite + Dexie/IndexedDB).
- البيانات محفوظة داخل الجوال فقط. خذ نسخة احتياطية من الإعدادات.
- مفتاح Claude API ينحط من شاشة الإعدادات، ويُرسل مباشرة لـ Anthropic.
- النشر تلقائي على GitHub Pages عند الدفع لـ `main` (`.github/workflows/deploy.yml`).

## التشغيل محلياً
```bash
cd app && npm install && npm run dev
```

## مصدر نص القرآن
نص المصحف في `app/src/quran/quran-simple.txt` من [مشروع تنزيل](https://tanzil.net)، منقول كما هو بدون تعديل، مع إشعار الحقوق في نهاية الملف.

صوت القراء في النسخة المستقلة من [everyayah.com](https://everyayah.com).
